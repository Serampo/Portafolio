# 🛠️ How to Navigate this Repository
To view the code for a specific project, you have two options:

  1. Via Web (GitHub)
  In the top-left corner of the file list, click the button labeled main (or the current branch name) and select the project    branch you wish to explore from the dropdown menu.
  
  2. Via Terminal (Local)
  If you want to clone a specific project branch to your computer, use the following command:
  
  Clone only a specific branch:
  
  Bash
  
  git clone -b branch-name --single-branch https://github.com/your-username/your-repository.git
